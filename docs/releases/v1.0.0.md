# Codex 动态壁纸 / Codex Live Wallpaper v1.0.0

**2026-10-15 替换构建 / Replacement build:** 保持版本号 1.0.0 和原发布地址，安装包与校验文件已重新构建。 / The version and release URL remain unchanged; the installer and checksum have been rebuilt.

## 简体中文

这是继 v0.3.6 后的第二次大版本更新，版本号为 **1.0.0**。
**项目维护者已在另一台 Windows 10 电脑实测通过，确认此前反馈的使用流程目前正常。**

### 本次更新

- 10 月 15 日修复预览服务归属和实例校验问题：临时聊天桥接退出不再留下失效缩略图地址，播放器复用及页面恢复后本地回退仍使用正确的实例身份。
- 修复作者图片 HTML 被截断后显示内部字段名的问题；说明、署名及主页链接收进折叠的“作者说明”，装饰图片不再冒充参数，颜色框改为紧凑色块，原参数值保留。
- 全新右侧壁纸编辑侧栏，独立齿轮通用设置，可调整面板材质、主题和字体。
- 按原壁纸比例展示预览，白色裁剪框保持 Codex 窗口比例，支持缩放、拖动以及完整显示/铺满。
- 本地壁纸库增加静态分类；轮播提供九个间隔选项，最长 12 小时。
- 修复预览请求与界面重建之间的状态问题；缩略图网络加载失败时读取已注册的本地预览。
- 首次通过配套启动器打开时显示壁纸库，之后恢复保存的壁纸与设置。
- 壁纸作者参数放在独立“设置”页；Scene 失败时提供错误解释与可复制的 AI 排查信息。
- 大视频转码保留源音轨为 AAC，不再复用旧的无声缓存。
- 安装包、桌面/开始菜单快捷方式和卸载入口统一使用 ChatGPT 图标，快捷方式名称保持 Codex Live Wallpaper。
- 安装目录包含原生卸载器 `unins000.exe`，卸载保留壁纸设置、缓存与 Codex 登录文件。
- 安装、升级、卸载前检测后台 Codex 或本安装的壁纸服务，并给出中英退出提示，不自动结束用户进程。

### 下载与安装

下载 `CodexLiveWallpaper-Setup-1.0.0-x64.exe` 及对应 `.sha256` 校验文件。
支持 **Windows 10 / Windows 11 x64**，内置 Node.js；需已安装 Codex，并已下载本地 Wallpaper Engine 项目。

**安装、升级或卸载前，请保存工作并完全退出 Codex，包括后台进程。**
只关闭窗口可能仍有后台进程；请在任务管理器中确认退出，再重试安装。
安装后通过 **Codex Live Wallpaper** 快捷方式启动，再在壁纸库中选择壁纸。
已有 1.0.0 安装也需要重新下载此次替换的 EXE 和对应校验文件，退出 Codex 后再次运行安装包；版本号不变。

本安装包未签名，不包含壁纸素材，也不提供独立 ZIP 便携版。
部分 Scene 特效受渲染器与硬件兼容性限制，可能回退为预览或显示错误；Web / Application 项目仍仅显示预览。
已有定制插件安装不会自动迁移。反馈时请提供 Windows/Codex 版本、壁纸类型及脱敏错误信息。

## English

This is the second major update after v0.3.6, numbered **1.0.0**.
**The project maintainer tested it successfully on another Windows 10 computer and confirmed that the previously reported workflow now works.**

### Highlights

- October 15 fixes: keep preview ownership with the launcher service and validate local-thumbnail fallback against the retained renderer instance, including after document restoration.
- Prevent truncated author image tags from exposing internal property keys. Collapse author notes, credits and safe links, omit decorative images, and use compact color swatches without discarding saved parameter values.
- Redesigned right-docked wallpaper sidebar and separate gear settings for panel material, theme and font.
- Source-proportional preview with a Codex-window-shaped crop frame, zoom/drag controls and Complete/Cover modes.
- Static library filter and nine rotation intervals, up to 12 hours.
- Preview-request and UI-rebuild fixes, with registered local thumbnails as a fallback for failed HTTP loading.
- Launcher-owned first-use library and saved wallpaper/settings restoration.
- Separate author-settings tab, actionable Scene error guidance and copyable AI diagnostics.
- AAC-preserving large-video conversion that does not reuse old silent cache entries.
- ChatGPT icon for the installer, desktop/Start menu launchers and uninstall display; distinct Codex Live Wallpaper names retained.
- Native `unins000.exe` in the installation directory; uninstall retains wallpaper settings, caches and Codex account files.
- Background Codex/wallpaper-service detection before install, upgrade and uninstall, with bilingual exit guidance and no automatic process termination.

### Verified

- Maintainer-confirmed successful testing on another Windows 10 computer.
- All 140 regression tests passed for this replacement build, along with desktop/narrow-screen light/dark author-control checks, preview-service handoff, sidebar interaction, crop ratio, persistence, audio, versions, icons and background-process blocking.
- Isolated install/reinstall/native-uninstall and settings/cache/synthetic-account-file retention checks passed during version 1.0.0 validation.
- The Windows 10 device and complete installation-lifecycle results above are from the original release. This replacement has not repeated that computer's cold-start, long-duration or full install/uninstall checks; current-window repairs and isolated browser checks passed.

### Installation

Download `CodexLiveWallpaper-Setup-1.0.0-x64.exe` and its `.sha256` file.
Supports **Windows 10 / Windows 11 x64** with bundled Node.js. Codex and local Wallpaper Engine projects must already be installed.

**Save your work and fully exit Codex, including background processes, before installing, upgrading or uninstalling.**
Closing the window may leave Codex running; confirm in Task Manager, then retry.
Launch using **Codex Live Wallpaper** and select a wallpaper from the library.
Existing 1.0.0 installations should download the replacement EXE and matching checksum, exit Codex, then run the installer again; the version number is unchanged.

The EXE is unsigned; wallpaper media and a separate portable ZIP are not included.
Scene compatibility depends on the renderer, project and hardware; unsupported projects may show a preview or an error. Web/Application projects remain preview-only.
Customized plugin installations are not automatically migrated. Remove personal paths and secrets from diagnostics before reporting issues.
