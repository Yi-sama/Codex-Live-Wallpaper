# v0.3.6 - 首个正式版

**Codex Live Wallpaper 首个正式版现已发布。**

把本地 Wallpaper Engine 视频和兼容的 Scene 壁纸放进 Codex 窗口，提供壁纸库、轮播、外观调节、声音控制及保存恢复。修改的是 Codex 窗口背景，不是 Windows 桌面壁纸。

**目前仅支持 Windows 10 / Windows 11 x64。** 暂不提供 macOS、Linux、Windows ARM64 或独立便携 ZIP。正式发布不代表没有问题，部分兼容性、启动与播放问题仍在持续改进。

## 下载

- `CodexLiveWallpaper-Setup-0.3.6-x64.exe`：当前用户安装包，内置 Node.js。
- `CodexLiveWallpaper-Setup-0.3.6-x64.exe.sha256`：安装包 SHA-256 校验文件。

安装包不含 Codex、Wallpaper Engine 或壁纸素材，需要事先安装官方 Codex 桌面应用，并准备已下载到本地的 Wallpaper Engine 项目。Codex CLI 需要支持插件命令。

安装包**尚未签名**，Windows 或安全软件可能提示未知发布者。请仅从本仓库下载，并核对附件中的 SHA-256；不要关闭安全软件来跳过提示。

```powershell
Get-FileHash .\CodexLiveWallpaper-Setup-0.3.6-x64.exe -Algorithm SHA256
```

## 本版内容

- 本地视频、兼容的打包 Scene 动态背景，以及壁纸库搜索和轮播。
- 背景缩放、位置、模糊、遮罩、面板透明度及支持的作者属性调节。
- 支持的音轨静音、音量控制，Codex 不活跃时自动暂停。
- 保存壁纸和外观参数，在配套启动器及插件桥接加载后恢复。
- 默认外观：**背景模糊 3px、背景遮罩 10%、面板透明 20%**。显式设置和已保存参数优先，不会强制覆盖旧设置。
- 配套快捷方式、插件注册、诊断日志和保留壁纸数据的卸载。

## 安装与首次使用

1. 安装前保存正在进行的任务。运行 EXE，安装器不会自动关闭或重启 Codex。
2. 自行退出 Codex，再通过桌面或开始菜单的 **Codex Live Wallpaper** 快捷方式打开。
3. 新建对话，让 Codex“列出本地 Wallpaper Engine 项目”，再应用一个项目。首次选择后才会出现背景和皮肤调整面板。
4. 以后仍使用配套快捷方式启动。普通 Codex 图标不会启用壁纸桥接。

安装不需要管理员模式，不修改 Codex 安装文件或 Wallpaper Engine 原项目。

如需恢复普通外观，让 Codex 移除壁纸，之后使用普通 Codex 启动方式即可。EXE 版请通过 Windows“已安装的应用”卸载；卸载保留壁纸设置、缓存和 Codex 登录文件。

## 已知问题与注意事项

- **Scene 兼容并不完整。** WebWallGL 不是 Wallpaper Engine 官方运行时；部分特效、模型、字体或声音可能不一致、异常或回退为预览图。
- **部分项目仅支持预览。** 未打包 Scene (`scene.json`)、Web 和 Application 项目不会完整运行，也不会执行其中的网页或程序。
- **大视频转码会移除音轨。** 缓存后的无声视频无法通过音量控件恢复声音。帧动画回退也不等同于完整原视频。
- **启动与恢复仍可能遇到问题。** 启动器最多等待 90 秒，部分慢启动问题的根因仍未完全确认；环境、Codex 版本及插件安装方式都可能影响结果。
- **Codex 更新可能需要适配。** 本项目依赖实验性的本机调试桥接，不是官方壁纸扩展接口。
- **已有定制安装不会自动迁移。** 同 ID 插件已从其他 marketplace 安装时会触发冲突保护；不要直接覆盖原配置或绕过保护。
- **动态背景会额外使用资源。** 播放和转码会占用 CPU、GPU、内存及磁盘空间；如果影响工作，可暂停或移除背景。
- **调试入口只能留在本机。** 不要开放或转发调试端口。提交日志前先检查并移除个人路径、访问令牌和登录信息。

此前回归测试和隔离安装、重装、卸载检查已通过，但不等同于实际播放验收。此次按维护者决定直接正式发布，不追加实机验收；全新 Windows 10/11 环境、长时间播放及重启恢复的验证仍有限。

本项目为独立社区项目，非 OpenAI 或 Wallpaper Engine 官方产品。保留上游版权及第三方许可声明，不附带任何壁纸素材。
